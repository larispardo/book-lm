# book-lm

A glass-box language model trained on the Sherlock Holmes canon, built step by step
while reading Chip Huyen's *AI Engineering*.

- `main`: the guided build, one milestone at a time.
- `solutions`: a complete reference implementation to peek at when stuck.

Code: MIT. Corpus: Project Gutenberg, public domain. Base model: SmolLM2 (Apache-2.0).
